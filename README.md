# SQL Academy

Интерактивная учебная платформа по SQL и PostgreSQL с приоритетом подготовки Junior Data Analyst.

## Образовательная программа

В каталоге доступны два самостоятельных курса:

- **SQL для аналитика данных:** самостоятельный начальный курс, 17 модулей и 112 уроков. Реляционная модель, SELECT, фильтрация, агрегация, JOIN, подзапросы, CTE, даты и время, оконные функции, аналитические метрики и рабочий процесс аналитика.
- **PostgreSQL:** самостоятельный углублённый курс, 8 модулей и 61 урок. DDL/DML, транзакции, представления, индексы, планы выполнения, расширенные возможности, безопасность и эксплуатация.

Каталог показывает только реализованные курсы. PostgreSQL можно проходить отдельно; базовые знания SQL рекомендуются, но прогресс двух курсов учитывается независимо.

## Возможности

- 173 урока с теорией, примерами, целями обучения и ссылками на документацию PostgreSQL. Каждый урок дополнен отдельным объяснением сложной логики и уникальным практическим экспериментом, безопасный читающий SQL можно выполнять прямо на странице урока.
- 42 пошаговых сценария для тем, где важно увидеть изменение строк, групп или окон.
- 173 вопроса внутри уроков и 100 вопросов на уровне модулей в отдельном разделе «Контрольные работы».
- 130 практических заданий с автоматической проверкой SQL, распределённых по самостоятельным курсам; связанные задания доступны также непосредственно внутри уроков.
- Отдельный раздел бизнес-проектов: E-commerce, аналитика доставки и Product Analytics; 9 самостоятельных заданий с SQL-автопроверкой, финальной аналитической запиской, проверкой интерпретации и отдельным сохранением черновиков.
- SQL-песочница на PGlite: PostgreSQL в WebAssembly прямо в браузере.
- Генератор из 350 вариантов заданий по 14 темам.
- Стартовая схема из 9 таблиц, историческая e-commerce модель из 4 таблиц и отдельная событийная таблица Product Analytics на 576 сессий.
- Дорожная карта, глоссарий из 72 терминов и SQL-шпаргалка из 13 разделов.
- Сохранение прогресса курсов, SQL-заданий проектов, SQL-черновиков и итоговых аналитических записок в localStorage браузера; отметки уроков используют устойчивые ID и мигрируют автоматически.
- Резервное копирование и восстановление локальных данных обучения в JSON: прогресс курсов, контрольные работы, черновик песочницы, задания проектов, SQL-черновики, записки, интерпретации и тема оформления. Восстановление проверяет формат и совместимость данных, требует подтверждения и откатывает частичную запись при ошибке.

## Публикация

Сайт публикуется через GitHub Pages. Workflow в `.github/workflows/pages.yml` проверяет синтаксис JavaScript и учебную базу, публикует сайт, затем запускает Playwright smoke test опубликованной страницы в Chromium: проверяет запуск и повторное подключение PostgreSQL, сохранение SQL-черновика, выполнение запроса, мобильную навигацию и узкие экраны.

Публичная страница: https://vladsimbro.github.io/SQL/

## Локальный запуск

Для статической версии открой локальный HTTP-сервер из корня проекта:

```bash
python -m http.server 8000
```

Затем перейди на http://localhost:8000.

Для проверки синтаксиса, учебной программы и SQL-решений:

```bash
npm install --no-package-lock
node --check app.js
npm run test:curriculum
```

Для браузерной проверки опубликованного сайта дополнительно установи Chromium и запусти:

```bash
npx playwright install chromium
npm run test:browser -- https://vladsimbro.github.io/SQL/
```

## Принцип работы и ограничения

SQL выполняется локально в браузере. Отдельный сервер курса не получает запросы пользователя. PGlite использует in-memory базу: изменения песочницы сбрасываются при перезагрузке страницы. Прогресс уроков и задач сохраняется в localStorage этого браузера.

Автопроверка сравнивает имена столбцов и значения результата; порядок строк учитывается только в заданиях, где он является частью условия. Изменяющие и транзакционные задания проверяются в отдельных временных экземплярах PostgreSQL, чтобы не портить общую учебную базу.

Платформа предназначена для изучения SQL и аналитики данных, а не заменяет полноценную серверную среду для нагрузочного тестирования и администрирования PostgreSQL.
