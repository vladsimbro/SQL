# SQL Academy

Полноценный статический учебный сайт по SQL с упором на PostgreSQL.

## Что внутри

- Пошаговая программа от баз данных и реляционной модели до оконных функций, транзакций, индексов, JSONB и аналитических кейсов.
- Подробная теория и SQL-примеры в каждом уроке.
- Дорожная карта с последовательностью модулей и отметками прохождения.
- 50 практических заданий с редактором и автоматической проверкой результата.
- SQL-песочница с настоящим PostgreSQL в WebAssembly через PGlite.
- Учебная логистическая схема из 9 таблиц.
- Шпаргалка и глоссарий.
- Прогресс и настройки темы сохраняются в localStorage.

## Запуск

Открой опубликованную GitHub Pages-страницу или запусти локальный статический сервер из корня репозитория. Например:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000.

PGlite загружается с jsDelivr при старте, поэтому для первого запуска нужен интернет. SQL выполняется внутри браузера; этот проект не отправляет запросы на собственный сервер. После перезагрузки свободная песочница и изменения учебной базы сбрасываются, а прогресс курса остаётся в браузере.

## Технологии

- HTML, CSS, JavaScript modules
- PGlite (PostgreSQL в WebAssembly): https://pglite.dev/docs/
- GitHub Pages

## Важные ограничения

Практический движок реализует PostgreSQL, но не заменяет отдельный PostgreSQL-сервер для изучения администрирования, сетевых подключений, конкурентной нагрузки и серверных настроек. В реальной работе отдельные версии PostgreSQL и другие диалекты SQL могут отличаться. Упражнения проверяют результирующий набор (имена столбцов и значения), поэтому эквивалентные по результату запросы принимаются независимо от оформления.


## Публикация на GitHub Pages

Workflow находится в `.github/workflows/pages.yml` и автоматически запускается при push в `main`. Для первого запуска нужно один раз включить Pages: **Settings → Pages → Build and deployment → Source → GitHub Actions**. После этого повторно запусти workflow во вкладке Actions или отправь новый commit. Workflow публикует статические файлы из корня репозитория.
