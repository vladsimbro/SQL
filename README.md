# SQL Academy

Открытый интерактивный учебный курс по SQL с практикой на PostgreSQL.

## Состав курса

- 25 последовательных модуля: от основ баз данных и реляционной модели до аналитики данных, транзакций, оптимизации и безопасности.
- 173 урока с теорией, примерами, целями обучения и ссылками на официальную документацию PostgreSQL.
- Все примеры SQL сопровождаются интерактивными пояснениями ключевых токенов и построчным разбором; ключевые темы дополнены пошаговыми сценариями с ожидаемым результатом и типичными ошибками.
- 100 интерактивных контрольных вопросов с разбором ответов.
- 102 практических задания с редактором и автоматической проверкой.
- Задачи на SELECT, DDL, DML и транзакции с SAVEPOINT. Изменяющие запросы и транзакционные сценарии проверяются в отдельных временных экземплярах PostgreSQL, не затрагивая общую учебную базу.
- SQL-песочница на PGlite — PostgreSQL в WebAssembly прямо в браузере; генератор случайных задач содержит 350 заданий по 14 темам, с выбором нескольких тем и проверкой ответа.
- Учебная схема из 9 таблиц интернет-магазина.
- Дорожная карта, глоссарий из 72 терминов, SQL-шпаргалка из 13 разделов и сохранение прогресса в браузере.

## Публикация

Сайт публикуется через GitHub Pages. Workflow в `.github/workflows/pages.yml` сначала устанавливает тестовую зависимость и запускает автоматическую проверку учебной базы и всех эталонных решений, затем развёртывает сайт.

Публичная страница: https://vladsimbro.github.io/SQL/

## Локальный запуск

Для статической версии можно открыть сайт через локальный HTTP-сервер:

```bash
python -m http.server 8000
```

Затем перейди на http://localhost:8000.

Для запуска CI-проверок:

```bash
npm install --no-package-lock
npm run test:curriculum
```

## Принцип работы и ограничения

Запросы в песочнице исполняются локально в браузере. Отдельный сервер курса не получает SQL-запросы. PGlite использует in-memory базу: изменения песочницы сбрасываются при перезагрузке страницы. Прогресс уроков и задач сохраняется в localStorage этого браузера.

Тренажёр предназначен для обучения SQL и PostgreSQL, но не заменяет полноценную серверную среду при изучении администрирования, сетевых подключений, конкурентной нагрузки, резервного копирования и эксплуатационных настроек.

Автопроверка оценивает итоговые имена столбцов и значения, а для отдельных DDL/DML-задач — состояние базы после команды. Эквивалентные SELECT-запросы принимаются, если возвращают тот же результат. Порядок строк не учитывается, когда он не влияет на смысл результата.
