## 2. Цель и подтверждённый объём

SQL Academy обучает самостоятельному решению аналитических задач на SQL с нуля до уверенного Junior Data Analyst. PostgreSQL — отдельный дополнительный маршрут, без смешения с администрированием в основном курсе.

- Основной маршрут: 17 модулей, 112 уроков.
- PostgreSQL: 8 модулей, 61 урок.
- Всего: 25 модулей, 173 урока.
- Практика: 121 обычное задание и 350 случайных вариантов по 14 темам.
- Контроль знаний: 100 вопросов.
- Учебная БД: 14 seed tables.
- Практические проекты: E-commerce, Delivery и Product Analytics; по три SQL-задачи в каждом.

Стабильные ID уроков и заданий сохраняются. Если изменение ID станет неизбежным, обязательна безопасная миграция существующего прогресса.

## 5. Последняя завершённая задача и одна текущая задача

### Последняя завершённая задача — модуль `views` дополнительного маршрута PostgreSQL

Все шесть уроков модуля проверены; исправлены ошибки в примерах функций и блоков PL/pgSQL, уточнена теория и добавлена отдельная практика для каждого урока.

- Исправлена ошибка dollar quoting: в примерах SQL-функций, триггеров, PL/pgSQL и DO-блоков теперь используется корректная форма `$$ ... $$`.
- Пример обработки уникального конфликта теперь передаёт все обязательные поля учебной таблицы, поэтому действительно попадает в `unique_violation`, а не в ошибку NOT NULL.
- Примеры VIEW и MATERIALIZED VIEW сделаны безопаснее для повторного запуска.
- Уточнено, какие простые VIEW автоматически обновляемы, а какие требуют дополнительной логики.
- Разобраны условия `REFRESH MATERIALIZED VIEW CONCURRENTLY`: уникальный индекс, уже заполненное представление и запрет на запуск внутри транзакционного блока.
- Уточнена разница между построчными и операторными триггерами, ограничения TRUNCATE и область применения INSTEAD OF.
- Добавлены шесть самостоятельных заданий: VIEW, обновление MATERIALIZED VIEW, SQL-функция, триггер, PL/pgSQL IF и обработка unique_violation.
- Smoke tests проверяют результаты всех шести заданий и корректное использование dollar quoting.
- Всего теперь 121 практическое задание; обновлены README, семь cache-busting imports и build `20261110-135`. Существующие IDs сохранены.
