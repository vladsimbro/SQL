## 2. Цель и подтверждённый объём

SQL Academy обучает самостоятельному решению аналитических задач на SQL с нуля до уверенного Junior Data Analyst. PostgreSQL — отдельный дополнительный маршрут, без смешения с администрированием в основном курсе.

- Основной маршрут: 17 модулей, 112 уроков.
- PostgreSQL: 8 модулей, 61 урок.
- Всего: 25 модулей, 173 урока.
- Практика: 125 обычных заданий и 350 случайных вариантов по 14 темам.
- Контроль знаний: 100 вопросов.
- Учебная БД: 14 seed tables.
- Практические проекты: E-commerce, Delivery и Product Analytics; по три SQL-задачи в каждом.

Стабильные ID уроков и заданий сохраняются. Если изменение ID станет неизбежным, обязательна безопасная миграция существующего прогресса.

## 4. Завершённая функциональная база

- Раздельные каталоги и прогресс двух учебных маршрутов.
- Hash-навигация, прямые ссылки, reload, Back/Forward.
- SQL Playground на PGlite и редактор CodeMirror.
- Практика, контрольные, справочник и глоссарий.
- Три проекта с SQL-проверкой и итоговой аналитической частью.
- Светлая и тёмная темы, мобильная навигация.
- Автосохранение прогресса и черновиков в localStorage.
- JSON backup с проверкой структуры, подтверждением и rollback при ошибке.
- Миграция legacy lesson IDs.
- CI: проверка синтаксиса JS, curriculum/PGlite smoke, Pages deploy и Playwright browser-smoke опубликованного сайта.

Известные продуктовые ограничения: PGlite работает в памяти браузера; прогресс и черновики привязаны к браузеру/origin; облачной синхронизации нет. Перенос между устройствами выполняется через backup.

## 5. Последняя завершённая задача и одна текущая задача

### Последняя завершённая задача — модуль `performance` дополнительного маршрута PostgreSQL

Все 15 уроков модуля проверены. Уточнены подсказки и примеры индексов, а практика расширена задачами, которые проверяют не только наличие объекта, но и его определение.

- Исправлены повторяющиеся подсказки: EXPLAIN-задачи теперь различаются по тому, что именно нужно найти в плане; подсказка к созданию индекса больше не предлагает вместо этого читать EXPLAIN.
- Задание `e101` теперь включает фильтр и агрегацию, чтобы действительно проверять чтение Scan, Filter и Aggregate.
- Примеры индексов и статистики сделаны безопаснее для повторного запуска через IF NOT EXISTS.
- Пример PREPARE теперь освобождает подготовленный запрос через DEALLOCATE.
- Добавлено предупреждение, что VACUUM нельзя выполнять внутри транзакционного блока, и что PGlite не заменяет мониторинг autovacuum на сервере.
- Добавлено `e122`: составной B-tree индекс с INCLUDE; проверяется порядок ключей и включённый столбец.
- Добавлено `e123`: частичный индекс; проверяется его WHERE-предикат.
- Добавлено `e124`: расширенная статистика для двух столбцов и запуск ANALYZE.
- Добавлено `e125`: EXPLAIN запроса с полуоткрытым диапазоном timestamp без преобразования столбца к date.
- Обновлены smoke tests: проверяются 125 заданий, 28 mutation-задач, 4 EXPLAIN и 4 transaction-задачи, а также структура новых индексов и статистики.
- Обновлены README, семь cache-busting imports и build `20261110-136`. Существующие IDs сохранены.
