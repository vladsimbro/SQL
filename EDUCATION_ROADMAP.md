# SQL Academy — маршрут образовательной переработки

Обновлён: 11 ноября 2026 года. Этот план **расширяет завершённый технический релиз**, а не объявляет старые фазы невыполненными.

## Цель и принцип готовности

Изучающий с нуля должен уметь не только объяснять SQL-конструкции, но и выбирать их самостоятельно в незнакомой аналитической задаче, проверять зерно, корректность расчётов и объяснять результат. Технически работающий сайт не означает педагогически завершённый курс.

**Критерий завершения программы:** все основные темы преподаются через объяснение → наблюдение результата → самостоятельное решение → работу с ошибками → смешанное повторение; задания и контрольные проверены на данных, отличных от примеров; проекты и финальный экзамен проверены; пользовательский маршрут опробован с нуля.

### Правила разработки

1. Реализовывать вертикальными законченными блоками: данные → UI → SQL-проверка → сохранение → тест → публикация.
2. Не считать число вопросов и страниц доказательством освоения; различать «прочитал», «решил», «подтвердил навык».
3. Бизнес-задачи в самостоятельном режиме не перечисляют нужные функции или таблицы, если это не часть требования.
4. Принимать эквивалентные SELECT и WITH SELECT по результату, не сравнивать строки SQL; для контрольных добавить изменённые контрольные наборы данных.
5. Не ломать уже сохранённые ID уроков, упражнений и проектов. Новые поля прогресса безопасно мигрировать, сохранять при экспорте и импорте резервной копии.
6. Никогда не объявлять этап завершённым только по тексту документации — требуются реальные файлы и успешные тесты.
7. После каждого блока обновлять этот файл, `PROJECT_STATUS.md` и `CHANGELOG_FOR_USER.md`; указывать SHA коммита и что делать следующим.
8. Не раздувать дорожную карту из-за новых идей: дополнительные предложения помещать в будущий backlog, не блокируя релиз.

## Этап 1: практическая реализация

Первый блок — три накопительные контрольные после сортировки, агрегаций и JOIN: в каждой по две самостоятельные SQL-задачи на сочетание пройденных тем. В отличие от имеющихся тестов, зачёт ставится только после реально корректных SQL-запросов, а не отметки о прочтении.

**Следующий блок после публикации:** педагогический эталон первых уроков, первая интерактивная практика внутри учебника и расширение контрольных с проверкой на дополнительных наборах данных.

## Подсчёт текущего базового контента

До переработки: 173 урока (112 SQL + 61 PostgreSQL), 130 обычных задач, 350 параметризованных вариантов, 100 модульных вопросов, три проекта с девятью SQL-задачами. Новые накопительные проверки учитываются **отдельно**, без подмены исходных показателей.
